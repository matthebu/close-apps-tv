# Close Apps TV

**Works with arthurjr.com only.** This Android TV app requires a TV paired with the ArthurJr server through wireless ADB.

[Download Close-Apps-TV.apk](https://github.com/matthebu/close-apps-tv/raw/refs/heads/main/Close-Apps-TV.apk)

After ArthurJr pairs with the TV and provisions the app, launch **Close Apps · ArthurJr** from the TV home screen and press **CLOSE APPS** on the remote. Keep wireless debugging enabled. ArthurJr stops eligible running apps and the TV displays the result. The app requires no Accessibility permission.

Version 0.2.0 replaces the earlier Accessibility edition. Its Android package name is `net.arthurjr.closer`, so it installs alongside the older app. Once the new button works, you can uninstall the old **Close Apps** entry.
